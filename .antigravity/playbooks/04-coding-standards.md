# 04-coding-standards.md

## Objective
Enforce strict, production-ready coding practices across all agents to guarantee maintainability and security.

## General Principles
*   Prefer clean, readable, maintainable code with sensible naming conventions[cite: 29].
*   Avoid unnecessary complexity[cite: 29].
*   Write code that is production-appropriate whenever possible[cite: 29].
*   Use clear folder structure and separation of concerns[cite: 29].

## Language and Framework Enforcement
*   Prefer TypeScript over plain JavaScript when practical[cite: 29].
*   Prefer strongly typed, maintainable patterns[cite: 29].
*   Use modern framework conventions instead of outdated patterns[cite: 29].

## Frontend Standards
*   Build responsive interfaces by default[cite: 29].
*   Prioritize accessibility[cite: 29].
*   Use reusable components and keep styling organized and consistent[cite: 29].
*   Handle loading, empty, and error states[cite: 29].
*   Use proper form validation[cite: 29].
*   Keep state management simple unless complexity justifies more[cite: 29].

## Backend Standards
*   Validate inputs and handle errors cleanly[cite: 29].
*   Use clear API design and keep business logic organized[cite: 29].
*   Use environment variables properly[cite: 29].
*   Add logging where useful[cite: 29].
*   Design database schemas thoughtfully[cite: 29].

## Security Standards
*   Sanitize and validate user input[cite: 29].
*   Do not expose secrets[cite: 29].
*   Use secure auth patterns[cite: 29].
*   Apply least-privilege thinking for roles and permissions[cite: 29].
*   Consider rate limiting, abuse prevention, and secure file handling when relevant[cite: 29].

## Code Output Rules & Quality Expectations
*   Code should run or be very close to runnable[cite: 29]. Do not provide placeholder pseudo-code unless explicitly requested[cite: 29].
*   Include comments only where they genuinely help[cite: 29]. Prefer clarity over cleverness[cite: 29].
*   Explain tradeoffs when making technical decisions[cite: 29].
*   **Code Generation Requirements:** When generating code, include project structure, file names, full file contents, install steps, run steps, environment variable setup, and deployment guidance if relevant[cite: 29].
